# Excel to PDF Professional

تطبيق سطح مكتب مجاني ومفتوح المصدر يحوّل مصنفات Excel إلى PDF **مقروء وقابل للطباعة ومُتحقَّق منه**.
لا يُسلَّم الملف على أنه سليم إلا بعد **قياس PDF الناتج فعليًا**: هل ظهر نص كل خلية؟ ما أصغر خط؟ هل توجد `###` أو صفحات فارغة؟

## التشغيل على أي جهاز Windows (دون Python)

1. نزّل `ExcelToPDF-Professional-<الإصدار>-win64.zip` وفك ضغطه في أي مجلد.
2. شغّل `ExcelToPDF\ExcelToPDF.exe`.
3. يحتاج البرنامج **LibreOffice** (مجاني) أو **Microsoft Excel**. إن لم يجد أيًّا منهما يعرض عليك تثبيت LibreOffice بنقرة، ثم اضغط «المحركات» للتحقق.
4. اسحب ملف Excel إلى النافذة ← اختر الأوراق ← «معاينة PDF» ← «تصدير».
5. **التحديث:** زر «التحقق من التحديثات» ينزّل الإصدار الجديد ويثبّته تلقائيًا (من 0.3.2 فما بعد).

يعمل محليًا بالكامل: لا يُرفع أي ملف إلى الإنترنت (الاتصال الوحيد هو التحقق من التحديثات على GitHub)، والملف الأصلي لا يُعدَّل أبدًا (يُتحقق من بصمته SHA-256 قبل وبعد).

## كيف يتعامل مع الحالات الصعبة

| الحالة | المعالجة |
|---|---|
| ورقة عريضة (أعمدة كثيرة) | تقسيم أفقي مع تكرار صف العناوين وعمود المفتاح، ولا ينزل الخط عن 8 pt (قابل للتعديل). |
| تثبيت صفوف وأعمدة / ترتيب الصفحات | قسم **«القالب»**: الصفوف والأعمدة الثابتة (من التجميد في الملف أو الاكتشاف أو اختيارك)، وترتيب «عرضًا ثم لأسفل» حتى تأتي أجزاء السجل متتالية، وأرقام الصفوف عند غياب عمود ثابت. |
| أعمدة ضيقة (ملفات مصدَّرة من أنظمة) | توسيع ذكي في نسخة العمل بأقل عدد صفحات، والتواريخ والأرقام لا تظهر `###` أبدًا. |
| ورقة عريضة جدًا (4 أجزاء أفقية أو أكثر) | اقتراح وضع **بطاقة لكل سجل** (حقل: قيمة)، ويُطبَّق فقط إذا اخترته. |
| نص أطول من عموده يُقص بالخلية المجاورة أو بحافة الصفحة | يُلَفّ داخل خليته في نسخة العمل، ويُضبط ارتفاع الصف، ويُذكر في التقرير. |
| نص طويل جدًا، أو رابط/JSON لا يمكن لفّه | يُنقل إلى **ملحق النصوص الطويلة** في آخر الملف كاملًا وقابلًا للبحث، والخلية تعرض رقم الإحالة `[n]`. |
| رقم أعرض من عموده (`###`) | يُكتشف ويُمنع التسليم، لأنه فقد بيانات. |
| صيغ بلا نتائج محفوظة (ملفات مصدَّرة من برامج) | يحسبها المحرك، ويُذكر ذلك. |
| قيم خطأ (`#N/A`…)، تعليقات، روابط خارجية، ماكرو | تُطبع القيم كما هي، والتعليقات لا تُطبع، ولا تُحدَّث الروابط، ولا يُشغَّل الماكرو أبدًا. وكل ذلك يُذكر. |
| أوراق وصفوف وأعمدة مخفية | تُستبعد افتراضيًا مع ذكر السبب. |
| نص عربي RTL | يُدعم بالكامل. إن تعذّر إثبات ترتيب حروف خلية في طبقة نص PDF مع وجود كل حروفها في الصفحة، يُطلب فحصها بصريًا بعنوانها. |
| ملف محمي بكلمة مرور، تالف، XLSB، أو بنية ZIP مريبة | يُرفض برسالة واضحة. |

حالة التقرير النهائية: **اجتاز التحقق / اجتاز مع تحذيرات / لم يجتز**. وعند عدم الاجتياز لا يُحفظ الملف إلا بموافقتك الصريحة.

## للمطوّرين

```powershell
py -3.12 -m venv C:\venvs\x2p          # مسار قصير: حزم Qt تتجاوز حد 260 حرفًا في المسارات الطويلة
C:\venvs\x2p\Scripts\python -m pip install -e ".[excel,dev]"
C:\venvs\x2p\Scripts\x2p-gui           # الواجهة
C:\venvs\x2p\Scripts\x2p convert book.xlsx -o book.pdf --report r.json   # سطر الأوامر
python -m pytest                       # الاختبارات (التكامل يعمل على كل محرك مثبَّت)
python tools/build_windows.py          # بناء الحزمة المحمولة build/release/*.zip
```

خيارات `x2p convert` المهمة:
- `--mode auto|fit_width|one_page|keep_original|cards`
- `--long-text appendix|wrap`
- `--engine auto|libreoffice|excel`
- `--min-font 8`
- `--allow-failed`

رموز الخروج: `0` اجتاز، `1` لم يجتز، `2` ملف مرفوض، `3` الهدف موجود (استخدم `--overwrite`).
